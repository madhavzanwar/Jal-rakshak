# Frontend credits

## Code reuse
No source code was copied from other projects. The following open-source projects were
studied for UI ideas only (layout of an India risk dashboard, map legends, alert cards):

- PredictAid — `jaidevxr/aidisastermanagement` (MIT)
- FloodGuard — `abdulmunafz/hyperlocal-intelligence-for-flash-flood-prediction-risk--response` (Apache-2.0)

## Libraries (all MIT / ISC / Apache-2.0 / BSD)
React, React Router, Vite, vite-plugin-pwa / Workbox, Tailwind CSS, Leaflet, react-leaflet,
Recharts, zod, lucide-react (ISC), jsPDF, Vitest, Testing Library, Playwright, ESLint, typescript-eslint.

## Data & tiles
- Map tiles © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors (ODbL), attribution shown on every map.
  The dark command-centre look is a CSS filter over the standard OSM tiles.
- Weather / river data: [Open-Meteo](https://open-meteo.com/) (ECMWF, DWD ICON, GloFAS) via the backend.
- Logo and icons: original artwork (water drop + shield) created for JalRakshak.
